# تطبيق كاشيرك ومنظومة كافي | Kashirak & Kaffii System

## النسخة العالمية | Global Edition

منظومة متكاملة لنقاط البيع (POS) وإدارة المبيعات والمخزون والمتاجر الإلكترونية للأنشطة التجارية والمطاعم والصيدليات وتجارة التجزئة.

All-in-one Point of Sale (POS), inventory management, and e-commerce retail platform for businesses, restaurants, pharmacies, and retail chains.

---

### المميزات الرئيسية | Key Features:
- **نظام نقاط البيع (POS):** تسجيل المبيعات والفواتير والعمل دون اتصال بالإنترنت (Offline Mode).
- **إدارة المخزون والمنتجات:** مسح الباركود، تقارير الجرد، والاستيراد/التصدير عبر Excel.
- **الإدارة عن بُعد:** لوحة تحكم متقدمة لمتابعة الفروع والمبيعات لحظياً.
- **متجر إلكتروني متكامل:** واجهة متجر متزامنة تلقائياً مع المخزون والطلبات.
- **دعم ثنائي اللغة:** إمكانية التبديل السلس بين اللغتين العربية والإنجليزية (AR / EN).
- **تسعير عالمي مرن:** خطط اشتراك تناسب مختلف أحجام الأنشطة التجارية.
